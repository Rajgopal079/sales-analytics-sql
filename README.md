# Sales Analytics using SQL Server
A practical SQL Server project focused on solving real-world business scenarios using T-SQL.

## Project Overview
This project contains **50 scenario-based SQL queries** covering sales, customers, products, stores, revenue, profitability,
delivery performance, currency conversion, and business analysis.
The queries range from basic aggregations to advanced SQL techniques such as CTEs, window functions, ranking, running totals, 
and month-over-month analysis.
